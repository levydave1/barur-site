# שמירת דוחות יתרות בדרייב — התקנה חד-פעמית

כל ליד שמעלה דוח יתרות מקבל תיקייה משלו ב"ברור משכנתאות / לידים" (לפי מספר טלפון),
ובתוכה הדוח עצמו וקובץ טקסט עם הודעת הטלגרם. בטלגרם מגיע קישור לתיקייה.
דוח שהועלה בלי שהושארו אחריו פרטים נמחק אוטומטית אחרי 48 שעות.

1. להיכנס ל-https://script.google.com בחשבון הגוגל של העסק → "פרויקט חדש".
2. למחוק את מה שיש בעורך ולהדביק את כל התוכן של `scripts/drive-leads.gs`. לשמור.
3. לבחור למעלה את הפונקציה `setup` → "הפעלה" → לאשר הרשאות (Drive).
   ביומן הביצוע יופיע סוד ארוך — להעתיק אותו (לא לשלוח בצ'אט).
4. "פריסה" → "פריסה חדשה" → סוג: "אפליקציית אינטרנט".
   הפעלה בתור: **אני**. למי יש גישה: **כל אחד**. → "פריסה" → להעתיק את כתובת ה-URL (מסתיימת ב-/exec).
5. ב-Vercel → Project Settings → Environment Variables, להוסיף:
   - `DRIVE_SCRIPT_URL` = הכתובת משלב 4
   - `DRIVE_SECRET` = הסוד משלב 3
6. Redeploy לפרויקט ב-Vercel.

"כל אחד" אומר רק שאפשר לפנות לכתובת — בלי הסוד הסקריפט מחזיר unauthorized ולא נוגע בשום קובץ.
עד שהשלבים האלה נעשים, האתר ממשיך לעבוד כרגיל, פשוט בלי שמירה בדרייב.
